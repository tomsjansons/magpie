# magpie

Screenshot library and annotator for [niri](https://github.com/YaLTeR/niri)
and [Noctalia](https://noctalia.dev).

niri keeps taking the screenshots. magpie picks up every one it captures, lists
them in a Noctalia bar dropdown, and opens them in a small GPUI editor for
arrows, boxes, circles and text. Annotated versions are saved as variants of
the original, so you can copy any version or start a new one from it.

Work in progress. See [PLAN.md](PLAN.md).
